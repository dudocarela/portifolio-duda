Case Study Destaque

Decifrando o Ecossistema Tech: Análise de Empregabilidade

Uma análise profunda sobre as variáveis que regem a contratação e remuneração na área de dados em 2024.

01. O Problema

A disparidade entre o que as empresas pedem e o que o mercado paga gera frustração. Utilizei um dataset de 2.000 registros para mapear a realidade financeira do setor.

02. Metodologia

Apliquei Análise Exploratória (EDA) e limpeza de dados para remover outliers, focando na correlação entre ferramentas e salário médio.

03. Insights de Valor

Python e SQL são os maiores multiplicadores de renda. O trabalho remoto domina 65% das posições de alto nível, permitindo a atuação global.
