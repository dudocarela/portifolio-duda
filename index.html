Projetos de Engenharia

PROJETO 01 // DATA WAREHOUSE

IBGE: O Censo do Brasil em Dados Estruturados

Pipeline ETL que automatiza a extração da API SIDRA, tratando inconsistências e populando um DW PostgreSQL com suporte geoespacial (PostGIS) para análise de densidade urbana.

PROJETO 02 // MACHINE LEARNING

Motor de Recomendação Híbrido

Sistema funcional inspirado no Netflix. Combina Filtragem Colaborativa (comportamento) e Baseada em Conteúdo (NLP) para personalização de alta precisão em tempo real.

PROJETO 03 // FULL-STACK SAAS

OmniStock: Gestão Preditiva

SaaS completo Next.js com IA integrada para previsão de ruptura de estoque através de análise de séries temporais. Dashboard administrativo e pagamentos via Stripe.

PROJETO 04 // CORE SYSTEMS

DudaDB Core: Engine Relacional

Desenvolvimento de um banco de dados relacional em Rust. Implementação de B-Trees, gerenciamento de memória (buffer pool) e persistência binária customizada.

PROJETO 05 // INFRA & OPS

Sentinel: Telemetria em Tempo Real

Monitor de infraestrutura distribuída usando Go e WebSockets. Detecta anomalias de hardware em milissegundos através de análise estatística de fluxo.
