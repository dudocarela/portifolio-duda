Case Study

Mercado Tech: Uma Abordagem Analítica sobre Empregabilidade

01

Contexto e Problema

O mercado tech é vasto, mas confuso. Mapeei a disparidade entre requisitos técnicos e realidade salarial usando um dataset de 2.000 registros.

02

Metodologia

Apliquei EDA (Análise Exploratória) e normalização de dados para validar o impacto do modelo Remote-First no mundo.

03

Insights Estratégicos

Profissionais com Python + SQL faturam 35% mais. O trabalho remoto domina 65% das vagas de alto nível, eliminando fronteiras.

Conclusão

Dados são o passaporte para o mundo. O storytelling com dados é o que diferencia o profissional médio do talento de elite.
