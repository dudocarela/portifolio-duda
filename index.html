Case Study

Decifrando o Ecossistema Tech: Uma Abordagem Analítica sobre Empregabilidade e Renda

01. Introdução e Contexto

No atual cenário de transformação digital, o mercado de tecnologia é frequentemente descrito como um oceano de oportunidades. No entanto, decisões de carreira não devem ser baseadas em suposições, mas em evidências. Este projeto mapeia as variáveis que regem a contratação e a remuneração no setor, focando em Data Science.

02. O Problema e a Coleta

A principal dor identificada foi a disparidade entre requisitos técnicos e realidade salarial. Utilizando um dataset com mais de 2.000 registros, apliquei técnicas de limpeza e normalização para remover outliers e entender quais hard skills possuem maior correlação com a valorização financeira.

03. Metodologia Aplicada

A análise foi estruturada em três pilares: Análise Exploratória (EDA) para padrões de contratação; Segmentação por Senioridade; e Mapeamento Geográfico para validar o impacto do modelo Remote-First em vagas globais.

04. Insights Extraídos

Os dados revelaram que profissionais que combinam Python com SQL possuem uma média salarial 35% superior aos que dominam apenas visualização. Além disso, o modelo remoto é padrão em 65% das vagas de alto nível, eliminando fronteiras para talentos qualificados.

05. Conclusão Estratégica

A Ciência de Dados é o passaporte definitivo para a economia global. Este estudo reforça que o domínio técnico, aliado à capacidade de contar uma história com dados (storytelling), é o que permite a um profissional brasileiro atuar em projetos de impacto internacional com alta performance.
